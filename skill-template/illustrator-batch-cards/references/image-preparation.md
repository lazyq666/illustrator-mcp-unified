# 图片优化与混合交付

在检查本次位图素材、决定置入方式及准备交付时读取。流程为：检查源图尺寸 → 区分大图与小图 → 询问大图是否缩小 → 大图链接、小图嵌入 → 重开检查。

## 置入方式

默认沿用 1600 px 阈值，按用户确认的源素材在本次优化前的长边判断。用户明确指定其他分类规则或个别素材的置入方式时，以用户要求为准。

| 素材 | 默认处理 |
| --- | --- |
| 源图长边大于 1600 px | 大图：外部链接；同意缩小时链接优化副本，拒绝时链接原尺寸副本 |
| 源图长边小于或等于 1600 px | 小图：直接嵌入 AI，保留原尺寸；小型位图图标、装饰图同样适用 |
| 名称字稿、矢量图标 | 按[PDF 字稿导入流程](pdf-vector-import.md)复制为可编辑路径，或复用已验收的 AI 字库，不按位图链接或嵌入处理 |

大图缩小至 1600 px 后仍按原分类使用链接，避免优化完成后重新归为小图。把源尺寸、优化后尺寸和最终置入方式记录到素材对应表。尺寸未知时先读取或定位源文件，不默认把全部素材变成链接。

## 检查与询问

只处理用户已确定用于本次卡牌的位图。记录来源路径、像素宽高和文件大小，汇总大图与小图数量。读取模板中图片实际置入的物理尺寸，必要时询问印刷规格。

按实际情况提示，替换示例中的数量和尺寸：

> 本次有 N 张角色图的长边超过 1600 px。可以等比例缩小至长边 1600 px，以减轻 Illustrator 的图片处理负担。若整幅图片长边在版面上为 80 mm，约为 508 PPI；能否满足印刷精度还需结合实际置入尺寸和印刷要求。是否开启「尺寸缩小＋无损压缩保存」？会保留原图，另存优化副本。缩小会减少像素，无损压缩仅指保存时不再增加有损压缩。

可提供「开启，使用优化副本」和「不开启，保留原尺寸」两个选项。允许用户只授权部分图片，并记录范围。一般的「开始制卡」不自动等于授权缩小图片；此前已明确授权则直接执行。等待期间可以继续检查模板和整理素材，不能将未回复当作同意。

有效 PPI = 图片像素数 ÷ 图片置入后的对应长度（英寸）。例如：1600 ÷ (80 ÷ 25.4) = 508 PPI。应使用整幅图片的实际置入长度；蒙版只显示其中一部分或图片放大时，不能用卡牌边长代替图片长度。只修改文件的 PPI 标签不会减少像素，也不能证明印刷精度提高。

## 获得同意后的处理

1. 保留原始图片，只为需要外部链接的大图在交付目录下建立 `Links/`。用角色编号及可区分的文件名保存实际引用素材，避免同名覆盖；同一素材用于多张卡时可复用。
2. 对授权范围内长边大于 1600 px 的图片，按 `1600 / max(宽, 高)` 等比例缩小，短边取整数，采用适合缩小的高质量重采样。保持方向、透明通道与颜色配置；不通过裁切凑尺寸。长边不超过 1600 px 的图片不缩放。
3. 使用实际可用的图片处理工具另存无损压缩副本。普通 RGB 或带透明度的图片可使用 PNG 无损压缩；需要保留 CMYK 等颜色模式时，使用 Illustrator 支持且能保留该模式的 TIFF 无损压缩（例如 ZIP 或 LZW）。核实所用工具确实保留颜色配置与透明度。避免为减小体积擅自改成有损 JPEG、减少颜色数量或移除透明通道。
4. 重新读取输出文件，核对像素尺寸、宽高比、方向、透明度和颜色，并记录原路径、输出路径及处理前后文件大小。无损格式的文件体积不保证小于原 JPEG；据实报告，不为满足体积预期擅自改用有损压缩。
5. 将大图在逐卡对应表中的置入路径指向优化副本。用户拒绝缩小的大图按原文件复制到 `Links/` 后链接；小图直接嵌入，不作为外部依赖放入 `Links/`。处理失败的图片标明失败原因，保留原图；改变已确认方案前告知用户并确认。

这一步不生成新的角色画面，不改变人物内容，也不覆盖来源素材。

## 混合交付

存在大图链接时，建议交付结构如下；`Links/` 仅放实际链接的大图，小图已存入 AI：

```text
交付目录/
  卡牌.ai
  Links/
    56_角色名称_1600.png
    57_角色名称_原尺寸.png
```

优先在置入前把需要链接的大图放到最终的 `Links/` 目录。若移动过素材，重新链接到交付目录中的实际文件；最终 AI 的外部引用不能继续指向临时目录、下载缓存或用户原始素材目录。没有外部链接时，无需创建空的 `Links/` 目录。

保存时保留大图的外部链接和小图的嵌入状态，不使用将所有图片统一嵌入或统一转链接的批量操作。对已有链接的小图执行嵌入后，重新获取对象引用，因为对象类型或标识可能改变。大图链接可以减轻文档负担，但复杂效果、预览和保存兼容设置仍可能影响文件大小与打开速度，不承诺具体提速比例。

从最终交付目录重开 AI，通过新的调用获取文档对象，在「链接」面板或等效接口逐项核对素材对应表：大图为链接，来源指向交付目录中的文件，没有缺失或待更新状态；小图已嵌入且不依赖源文件路径。仍需查看实际画面，确认缩小、置入或嵌入没有改变裁切和破框对齐。存在大图链接时提醒用户携带 AI 与 `Links/`；已嵌入的小图不需要另附文件。
