# PDF 字稿导入与渐变衬边

名称替换流程为「PDF → 导入可编辑路径 → 重建渐变衬边」。输入是已准备的矢量 PDF；由 PDF 导入并验收的 AI 字库可作为路径缓存直接复用。PDF 图标等路径素材使用相同的导入与核验方式，仅在模板需要时添加衬边。位图另按大图链接、小图嵌入的规则处理。

## 1. 检查 PDF 字稿或已有字库

确认字稿是整组名称还是独立单字，建立文件、页码或字形组与角色名称的对应关系。检查缺字、轮廓边界、填充、镂空和裁切结构。扩展名为 PDF 不代表内容是矢量；若名称实际是一张位图，应标为字稿不可用，不能将其当作可编辑路径继续制作。

已有 AI 字库时，核实字形来自 PDF 导入且已通过路径与镂空检查，只复制字形组，不带浏览标签、字格或预览背景。同一字形验证后复用，无需逐卡重新打开 PDF。

若输入只有 SVG，先查找已有矢量 PDF 或已验收字库；确实缺少时，将一次性转换作为独立的素材准备步骤，在现有任务授权范围内完成后再进入本流程。保留原 SVG、填充规则和镂空，核验转换结果；已有合格 PDF 时不重复转换，也不把 SVG 转换列为每次制卡的必经步骤。

完成条件：待用名称所需字形齐全，来源与对应关系明确，输入包含可编辑矢量。

## 2. 导入可编辑路径并排好名称

按[工具选择与脚本执行](script-execution.md)，通过已验证的入口在 Illustrator 中打开 PDF，取得实际矢量对象，按原叠放顺序复制到卡牌目标图层，再整理为名称字面组。复制分组时保留内部复合路径和裁切关系，仅复制最外层对象，避免子对象被重复复制。

使用「打开 PDF 后复制路径」，不要将 PDF 作为外部链接图片置入。仅执行嵌入也不足以通过验收，必须核实结果可以编辑路径节点。需要统一填充色时保持复合路径结构，不将镂空拆成实心形状或白色填充。

统一 MCP 的 `import_pdf_as_paths` 接受已转轮廓的矢量 PDF。本机 Illustrator 30.2.1 跨文档直接复制到分组可能报 MRAP，因此先复制到目标图层，再在目标文档内移入字面组；不使用剪贴板。缩放按实际有填充或描边的字形范围计算，排除 PDF 页面的空白裁切边界，同时保留原裁切结构。不能只看字面组的几何边界判断最终字高，须检查实际字形及导出画面。

单字先按已确认名称拼接，沿用字库的尺寸校准，保留各字自然宽窄和高矮。依据当前模板确定字距、整组等比例缩放和中心位置；名称过宽时缩小整组，不横向挤压字形。排好字面并确定最终尺寸后，再创建衬边。

仅关闭本次打开的临时 PDF，回到明确的目标文档；保留用户原有文档。最终字面不依赖 PDF 或字库文件的外部链接。

完成条件：名称正确，字面由可编辑路径或复合路径组成，位置、比例与镂空通过核对。

## 3. 重建渐变衬边

先读取当前模板旧名称的字面与衬边结构，记录渐变色标、方向、偏移路径厚度及叠放关系。模板已有独立衬边轮廓时可根据字面与衬边边界估算厚度，再对照实际画面校准；不沿用其他模板的固定数值。

将已定位的名称字面复制到后方，命名为独立衬边组，应用模板渐变与偏移路径效果。渐变应随新名称的位置和尺寸重新定位，不能只复制渐变色标而遗留旧名称的渐变坐标。

默认保留可调整的偏移路径效果；仅在交付要求或后续编辑需要时展开为实际轮廓。字面与衬边保持独立，便于重新拼字、调整厚度和替换颜色。生成后在最终卡牌背景上检查细节，尤其是小孔洞、相邻笔画和字间空隙。

完成条件：衬边位于字面后方，渐变、厚度与模板匹配，字面镂空及字间关系正常。

## 4. 保存重开后核验

- **结构**：字面与衬边分组清楚；字面保留实际路径或复合路径，没有替代字稿的链接对象、位图或不可编辑占位对象。
- **镂空**：与源 PDF 或已验收字库对照孔洞和透明区域；必要时在预览副本中使用对比色背景，区分真实镂空和白色填充。
- **外观**：名称、尺寸、比例、位置、渐变、衬边厚度及叠放正确，没有重复笔画或额外背景。保存后重新打开并导出画面核对。
- **依赖**：最终名称无需携带源 PDF 或字库作为外部链接；这些文件可保留为可复用的素材。

路径不可编辑、镂空丢失或衬边不符时，该名称未通过验收。定位受影响的导入或效果步骤，修正并重新核验后再批量复用。
